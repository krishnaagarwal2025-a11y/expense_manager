# **App Name**: ClanSplit

## Core Features:

- Nested Hierarchy Builder: A structural setup tool to define recursive family trees and groups where members or sub-nodes represent a share of the total bill.
- Firestore Data Synchronization: Storage of the complex nested group logic and expense logs using Firestore for real-time updates across clan heads.
- Intelligent Allocation Tool: An AI-powered natural language tool to process raw expense descriptions and automatically identify which family node should be billed based on previous entries.
- Offline Mode Service Worker: A background script ensuring that trip expenses logged in remote locations are saved locally and pushed to the cloud upon reconnection.
- Expandable Family Dashboard: A high-level interface displaying balances between 'Clan Heads' with the ability to drill down into specific cousins or core units.
- Multi-Layered Settlement Engine: Algorithmically determines the most efficient way to settle debts across parent and child nodes to minimize the number of transfers.
- PWA Installation: Web-based installation allowing the app to sit on the mobile home screen for native-like performance and full-screen data entry.

## Style Guidelines:

- Primary color: Electric Cobalt (#5B73DB), selected to provide a modern and reliable feeling for financial data on a dark background.
- Background color: Deep Charcoal with blue undertones (#181B26), establishing a premium, agency-standard dark theme.
- Accent color: Airy Azure (#8FC9EF), used sparingly for contrast in active nested states and high-priority action buttons.
- Font pairing: 'Poppins' for clean, geometric headlines and 'Inter' for highly readable financial figures and nested text blocks.
- An 'Indented Branch' layout inspired by recursive design, where nesting depth is communicated through subtle vertical border-lines and progressive spacing.
- Smooth layout transitions using Spring physics to animate the expansion and contraction of nested family nodes.
- Custom monochromatic line icons that emphasize connectivity and organizational hierarchy.
